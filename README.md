## Про програму

### Навіщо вона
В ОСББ заявки на ремонт часто губляться в чатах, матеріали рахують на папері, а розрахунки ведуть у різних таблицях.
Ця програма збирає все в одному місці й працює на звичайному комп’ютері, без інтернету й без сервера.
Дані лежать в одному файлі, який легко скопіювати.

### Що вона вміє
- **Заявки на ремонт.** Реєстрація заявки з джерелом (Telegram-чат, телефон, особисто, плановий огляд), місцем
  (спільне майно, під’їзд, територія, квартира), пріоритетом, статусом, виконавцем і термінами.
- **Персонал і підрядники.** Довідник штатних працівників та підрядних організацій.
- **Квартири й власники.** Довідник квартир із власниками й контактами.
- **Склад матеріалів і списання.** Для кожної заявки можна списати матеріали. Залишок на складі змінюється сам,
  а списати більше, ніж є, програма не дасть.
- **Види робіт.** Довідник робіт із вартістю, кількістю робітників, тривалістю й нормою матеріалу.
- **Розрахунки.** Два рахунки: «Загальний фонд» (цільові внески й централізовані витрати) та «Індивідуальний» рахунок
  квартири. Кнопка «Рахунок власнику» сама складає суму: робота плюс матеріали за рахунок власника плюс доплата за
  платний виклик, якщо вона є. Борг програма рахує сама.
- **Головна сторінка.** Відкриті заявки, аварійні й термінові, заборгованість квартир і баланс загального фонду.
- **Звіти.** Вісім звітів за вибраний період з експортом у CSV, який відкривається в Excel.
- **Ролі.** Адміністрація правління може змінювати дані, а користувач із роллю «Перегляд» лише дивиться таблиці й звіти.

Заявки з месенджерів (наприклад, із Telegram-чату) адміністратор вносить вручну, автоматичного імпорту немає.

### Для кого
Для адміністратора чи диспетчера ОСББ (роль «Адміністрація правління») і для членів правління, яким потрібен лише
перегляд (роль «Перегляд»).

### Що потрібно для запуску
Windows 10 або 11 (64-розрядна), близько 100 МБ місця. Встановлювати Qt не треба, потрібні бібліотеки вже входять
до інсталятора. Права адміністратора не потрібні.



## Встановлення

### Спосіб 1. Інсталятор (найпростіший)
1. Відкрийте вкладку **Actions** цього репозиторію й виберіть останній запуск «Build Windows exe» з зеленою або синьою галочкою.
2. Унизу, в розділі **Artifacts**, завантажте `parkovi_ozera_installer` і розпакуйте zip.
3. Запустіть `ParkoviOzera_Setup.exe`.
4. Якщо Windows пише «Windows захистила ваш ПК», натисніть **Докладніше → Все одно виконати**: інсталятор просто не має цифрового підпису.
5. Залиште позначку «створити ярлик на робочому столі» й натисніть **Далі → Встановити → Готово**.

Програма встановиться в `C:\Users\<ваше ім’я>\AppData\Local\ParkoviOzera`. Видалити її можна, як і будь-яку іншу,
через **Параметри → Програми**.

### Спосіб 2. Переносна папка
1. Завантажте `parkovi_ozera_windows` і розпакуйте **всю** папку туди, де вона лежатиме постійно.
2. Запускайте `parkovi_ozera.exe` із цієї папки або зробіть ярлик: правою кнопкою по exe → **Надіслати → Робочий стіл (створити ярлик)**.

Не виносьте сам exe з папки, інакше програма не запуститься: їй потрібні файли, які лежать поруч.

### Спосіб 3. Зібрати самостійно
Знадобляться Qt 6.5 або новіший (модулі Widgets і Sql), CMake 3.19+ і компілятор C++17.
```
git clone https://github.com/Aducia/osbb-parkovi-ozera
cd osbb-parkovi-ozera
cmake -S osbb_parkovi_ozera -B build -DCMAKE_PREFIX_PATH=<шлях до Qt>
cmake --build build --config Release
```
Або відкрийте `osbb_parkovi_ozera/CMakeLists.txt` у Qt Creator, виберіть комплект Desktop Qt і натисніть
**Configure Project**, потім **Build & Run**.



## Перший запуск
Запустіть програму з ярлика й увійдіть. Початкові логін і пароль я називаю під час захисту, у репозиторії їх немає.
Після першого запуску поруч із програмою з’являються два файли: `parkovi_ozera.db` (база з вигаданими демонстраційними
даними) і `users.ini` (облікові записи, паролі зберігаються у вигляді хешу). Перед реальним використанням
змініть початкові паролі через меню «Файл».



## Як користуватися

### Основні дії з таблицями
- **Додати:** відкрийте розділ, натисніть **Додати**, заповніть форму, **ОК**. Новий рядок буде зеленим.
- **Змінити:** двічі клацніть по комірці або виберіть рядок і натисніть **Змінити**. Змінений рядок буде жовтим.
- **Видалити:** виберіть рядок і натисніть **Видалити**. Видалений рядок буде червоним.
- **Зберегти:** зміни збираються й записуються разом кнопкою **Зберегти**. Кнопка **Скасувати** їх відкидає.
- **Знайти:** почніть вводити текст у полі пошуку над таблицею (Ctrl+F) і виберіть стовпець.

### Від заявки до розрахунку
1. **Зареєструйте заявку:** розділ «Об’єкти / Заявки на ремонт» → **Додати**. Вкажіть джерело, місце, пріоритет,
   вид роботи й опис. Якщо місце — «Квартира», виберіть квартиру.
2. **Призначте виконавця:** відкрийте заявку, виберіть виконавця, поставте статус «Призначена» й дату початку.
3. **Спишіть матеріали:** розділ «Списання матеріалів» → **Додати**. Виберіть заявку, матеріал, кількість і джерело
   коштів. Ціна підставиться сама, залишок на складі зменшиться.
4. **Закрийте заявку:** статус «Виконана» й дата закінчення.
5. **Виставте рахунок власнику:** розділ «Оплати» → **Рахунок власнику** → виберіть заявку по квартирі.
6. **Внесіть оплату:** вкажіть сплачену суму в рядку рахунку й збережіть. Борг перерахується.

### Звіти
Відкрийте «Звіти», виберіть звіт і період (датами або швидким вибором: поточний місяць, минулий місяць, поточний рік).
Кнопка **Експорт у CSV** збереже таблицю у файл із кодуванням UTF-8 й роздільником «;», тож Excel відкриє її без додаткових налаштувань.

### Копія даних
Закрийте програму й скопіюйте `parkovi_ozera.db`. Якщо видалити цей файл, наступний запуск створить нову базу
з демонстраційними даними. Якщо програма знайде базу старої версії, вона збереже її копією `parkovi_ozera_old_<дата>.db`
і створить нову.



## Довідка

### Розділи програми
| Розділ | Що там |

| Головна | Картки з ключовими показниками, списки відкритих заявок і боргів |
| Об’єкти / Заявки на ремонт | Усі заявки з пріоритетом, статусом і виконавцем |
| Списання матеріалів | Витрати матеріалів по заявках |
| Оплати | Загальний фонд та індивідуальні рахунки, борг, кнопка «Рахунок власнику» |
| Доплати та виклики | Тарифи платних викликів і спецбригад |
| Довідники | Персонал і підрядники, квартири, матеріали (склад), види робіт |
| Звіти | Вісім звітів за період |

### Звіти
Заявки за період · Вартість заявок за період · Оплати за період · Загальний фонд за період ·
Списання матеріалів за період · Заборгованість квартир · Персонал та підрядники · Види робіт та кошторисні норми.

### Допустимі значення
| Поле | Значення |

| Джерело заявки | Telegram-чат, Телефон, Особисто, Плановий огляд |
| Місце | Загальнобудинкове майно, Під’їзд, Прибудинкова територія, Квартира |
| Пріоритет | Аварійна, Термінова, Планова |
| Статус | Нова, Призначена, В роботі, Виконана, Скасована |
| Джерело коштів | Загальний фонд, Власник квартири |
| Рахунок | Загальний фонд, Індивідуальний |
| Виконавець | Штатний, Підрядник |

Дати вводяться у форматі РРРР-ММ-ДД і мають існувати в календарі.

### Що програма не пропустить
- списання більше, ніж залишок на складі;
- оплату більшу, ніж нараховано з доплатою;
- індивідуальний рахунок або заявку на квартиру без вибраної квартири;
- дату закінчення раніше за дату початку;
- дублікати: квартиру в тому самому корпусі, назву матеріалу, вид роботи, доплату, паспорт виконавця;
- видалення квартири, виду роботи чи матеріалу, які вже використані;
- нуль або мінус там, де число має бути додатним (кількість робітників, тривалість, кількість у списанні).

У таких випадках програма показує пояснення українською, а зміни не застосовуються.

### Терміни
| Термін | Що це |

| ОСББ | Об’єднання співвласників багатоквартирного будинку |
| Заявка | Звернення про несправність або плановий огляд |
| Списання | Витрата матеріалу зі складу по заявці |
| Загальний фонд | Рахунок цільових внесків і централізованих витрат |
| Індивідуальний рахунок | Нарахування квартирі за роботи за її рахунок |
| Доплата | Фіксована сума за платний виклик або спецбригаду |
| Борг | Нараховано плюс доплата мінус сплачено |



## Якщо щось не працює
| Що бачите | Чому | Що робити |

| «Qt6Widgets.dll was not found» | Exe винесли з папки програми | Запускайте його з папки або через ярлик |
| «Windows захистила ваш ПК» | Файл без цифрового підпису | **Докладніше → Все одно виконати** |
| Дані не зберігаються | У програми немає права запису в папку | Встановіть її в папку користувача, як це робить інсталятор |
| Повідомлення, що списання більше за залишок | На складі менше матеріалу | Зменште кількість або поповніть залишок у розділі «Матеріали» |
| Повідомлення про дублікат | Такий запис уже є | Змініть значення або відредагуйте наявний запис |
| Запис не видаляється | На нього посилаються інші дані | Спершу змініть або видаліть пов’язані записи |
| Збирання не знаходить Qt | Не вказано шлях до Qt | Додайте `-DCMAKE_PREFIX_PATH=<шлях до Qt>` або виберіть комплект у Qt Creator |



## Для розробника

### Структура репозиторію
| Шлях | Призначення |

| `osbb_parkovi_ozera/*.cpp, *.h` | Код: інтерфейс, моделі таблиць і звітів, робота з базою, вхід і ролі, стилі |
| `osbb_parkovi_ozera/sql/` | Схема БД, демонстраційні дані, запити звітів (вбудовуються в exe) |
| `osbb_parkovi_ozera/img/` | Логотип та іконка |
| `osbb_parkovi_ozera/CMakeLists.txt` | Збирання |
| `osbb_parkovi_ozera/installer.iss` | Скрипт інсталятора Inno Setup |
| `osbb_parkovi_ozera/tests/` | Автоматичні тести БД |
| `.github/workflows/build.yml` | Автоматична збірка exe й інсталятора |

### Тести
Я написала 23 автоматичні тести логіки бази (тригери, обмеження, обчислювані поля, запити звітів):
```
python osbb_parkovi_ozera/tests/db_tests.py
```
Потрібен Python 3. Тести перевіряють SQL із папки `sql`, графічний інтерфейс вони не охоплюють;
його я перевіряла вручну (результати в пояснювальній записці).

### Обмеження
- Немає кабінету мешканця та мобільного застосунку.
- Лише дві ролі.
- Послідовність статусів заявки не контролюється.
- База SQLite розрахована на одне робоче місце.
- Автоматичного резервного копіювання немає.
- Демонстраційні дані вигадані, навантажувальних випробувань не було.

### Персональні дані та безпека
У довіднику персоналу є поле «паспорт». У демонстраційній базі все вигадано. У реальному використанні варто
дотримуватися Закону України «Про захист персональних даних». Файли `parkovi_ozera.db` і `users.ini` не шифруються,
тож доступ до них обмежують засобами Windows.

### Ліцензії
Qt 6 використовується як динамічні бібліотеки (умови: <https://www.qt.io/licensing>). SQLite входить до Qt.
Інсталятор створено в Inno Setup. Код програми написано для навчання.
